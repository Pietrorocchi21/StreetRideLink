# MotoLink

**MotoLink** is a smart motorcycle device designed to provide navigation, riding information and accessory control directly from the handlebar.

The project aims to reduce distractions while riding: essential information is displayed on a dedicated screen, while the smartphone handles maps, routes and Internet connectivity.

## Overview

MotoLink is a device installed on a motorcycle that turns the handlebar into a simple and intuitive control point.

The system displays the most useful riding information, such as the next turn, remaining distance, speed and other trip data. This allows riders to access essential information without looking at their smartphone.

MotoLink is designed as an accessible, modular product suitable for different use cases, from everyday navigation to group rides.

---

## Project goals

MotoLink is being developed with the following goals:

- Provide clear and less distracting navigation
- Display useful information without requiring the rider to look at a smartphone
- Enable controls that can be used while wearing gloves
- Avoid the need for a dedicated SIM card in the device
- Offer optional features that can be enabled according to user needs
- Integrate music, action cameras and motorcycle travel services

---

## Target users

MotoLink is intended for:

- Riders looking for simple navigation without buying an expensive dedicated device
- Users who want to monitor speed, lean angle and trip information
- Groups of friends travelling together by motorcycle
- Motovloggers and content creators using action cameras
- Technology enthusiasts and motorcycle accessory users

## Planned features

### Navigation

- Essential turn-by-turn directions
- Distance to the next turn
- Smartphone connection for maps and routes
- Operation designed to work even without an Internet connection

### Riding information

- Dashboard with key data
- Speed and riding information
- Motorcycle lean angle
- Possible trip recording and history

### Connectivity

- Smartphone connection
- Useful notifications and alerts
- Possible integration with cloud services

### Accessories

- Action camera control, with GoPro as the first priority
- Possible future integrations with Insta360
- Features designed for group rides

## Waveify

MotoLink will integrate **Waveify**, a personal music service developed as part of the project ecosystem.

Waveify will offer:

- Free music with no advertisements
- Playlists and favourite tracks
- Music playback connected directly to MotoLink
- Quick controls for play, pause, next track and previous track
- An interface designed for use while wearing gloves

## Product versions

### MotoLink Core

MotoLink Core is the essential version of the device.

It is designed for navigation, riding information and simple physical controls.

### MotoLink Advanced

MotoLink Advanced is the more complete version.

It offers greater expansion capability and allows additional features to be enabled according to the user’s needs.

## Modular subscription

MotoLink features will not be included in a single rigid package.

Users will be able to enable only the functions they want to use, selecting them individually within themed categories.

Planned categories include:

| Category | Example features |
|---|---|
| **Travel** | Advanced navigation, GPX routes, trip history |
| **Camera** | GoPro or Insta360 control, recording and highlight tagging |
| **Squad** | Friend location, communication and group features |
| **Pro** | Advanced telemetry, riding analysis and professional features |
| **Music** | Waveify, playlists and music playback |

This model allows every rider to build their own MotoLink configuration and enable only the features they actually need.

## Future features

In addition to the core features, MotoLink may include:

- GPX routes and advanced trip management
- Advanced telemetry with acceleration, braking and riding analysis
- Cloud services for saving trips, statistics and configurations
- Black box recording of data before an incident
- Fall detection and possible emergency calling
- GPS anti-theft alerts in case of suspicious movement
- Real-time location of riding companions
- Group communication with a visual indicator showing who is speaking
- Mesh networking between MotoLink devices for group rides
- Dynamic weather alerts for rain or adverse conditions
- Night mode for more comfortable visibility
- Voice assistant and incoming message reading
- Action camera integrations to start, stop or tag recordings
- Waveify for music playback and playlist management
